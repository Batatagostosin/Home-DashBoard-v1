# Home Dashboard v1 (Porto)

A personal home dashboard built with **HTML**, **CSS**, **JavaScript**, and **Python**.
While the interface displays all information in **Portuguese** and comes pre-configured for **Porto, Portugal**, this repository provides a clean local hub for daily info and system monitoring.

## Features

- **Date & Time:** Real-time clock and calendar formatted in Portuguese (`pt-PT`), set to the Europe/Lisbon timezone.
- **Weather (Porto):** Current conditions and forecasts pre-configured for **Porto, Portugal**.
- **App Quick-Launch:** Shortcuts to open configured local applications directly from the dashboard.
- **Smart Task Manager:** Task list that automatically sorts items by **date** and **priority**.
- **Server System Metrics:** Live monitoring of **CPU** and **RAM** usage on the host machine running the Python backend.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python 3.x (`FastAPI` + `psutil` for hardware metrics)
